0.7.0
Windows: with JAWS running, holding an arrow in tape or spring seeking scrubs smoothly. JAWS passes a held arrow on as a new press and release for every repeat, so scrubbing started over some 30 times a second, in small jerks. FastPlay now looks at the keyboard's own arrows (only while its window is in front, and without taking them from anyone) to tell the key is still held.
In tape seeking, pressing Play (X) just after the last track has played to the end starts it again. It used to do nothing for a moment, while an inaudible tape stop ran down after the end.
Changing the pitch, tempo or rate while stopped or paused is heard as soon as it plays again. It used to play as much as the buffer holds with the old setting first, even when the file started over.
FastPlay plays Codec 2 (.c2), the speech codec for amateur radio, from 3200 down to 700 bits per second. The Open dialog shows .c2 files, opening one with Load Folder brings the rest of its folder, the library finds them, and FastPlay can be made their player.
Speex files (.spx) are among the file types FastPlay lists: the Open dialog shows them, opening one with Load Folder brings the rest of its folder, the library finds them, and FastPlay can be made their player. (It played them already.)
Scrubbing keeps the pitch and rate you have set. Tape scrubbing runs from the sound as you hear it (at +3 semitones and 4 times the speed, it is 27 semitones up) and winds back down to your pitch; spring scrubbing stays at your pitch. Before, scrubbing dropped to the file's own pitch and jumped back to yours when it ended.
Windows: starting FastPlay again while it runs (from the taskbar, a shortcut, or Windows+number) brings its window back, also when it was minimized to the system tray. It used to do nothing, so a FastPlay in the tray could only be got back from there.
669 and MO3 modules are among the file types FastPlay lists: the Open dialog shows them, opening one with Load Folder brings the rest of its folder, the library finds them, and FastPlay can be made their player. (It played them already.) MTM and UMX modules now come with a folder and into the library too, and MPTM modules show in the Open dialog and can have FastPlay as their player.
Windows: FastPlay plays audio CDs. Open a track on the CD drive (Track01.cda) and it plays straight from the disc, with the rest of the CD after it; seeking, tempo and effects work as with any file. When the disc has CD-Text, the title, artist and album come from it.
In tape seeking, pausing or stopping now slows the tape down the moment you press it. It used to fall silent for a moment first while FastPlay found its place in the file again, which took longest on CDs and slow files. Pressing Play (X) while the tape is still slowing calls the pause off, and it plays on from there; it used to start the track again from the beginning.
Holding the arrows to scrub (tape or spring) no longer falls silent for a moment when it starts, when you let go and when playing carries on, nor does a short jump back. FastPlay keeps the last half minute it has decoded and plays from that at once. Scrubbing back on a CD keeps up too.
iPhone and Android: where you are is saved when playback starts or stops and every half minute while it plays, so when the system ends FastPlay without warning (an update, or short of memory), Remember Playback State on Exit still opens it where you left off. On the iPhone, remembered positions, bookmarks and scheduled events also survive an update or restore that moves the app's folder. (#27)
Shift+V plays the file in reverse from where you are, with your effects, and again plays it forward. Seeking keeps going in reverse; at the start of the file it stops, paused. On the iPhone and Android, the player has a Reverse button.
Playback > Jump to Random Point goes somewhere at random in the file and says where. It can be given a hotkey. On the iPhone and Android, the player has a Random Point button.
iPhone and Android: pasting, downloading and syncing folders show how much of the file has come, how fast, and when syncing, how much there is in all and about how long the rest will take.
iPhone and Android: while folders auto sync, the Home screen shows how it is going under Auto Sync, and what each folder's sync did once it finishes. Settings > Auto Sync shows it on the folder being synced.
iPhone and Android: on the Home screen, Files has an action to paste what you cut or copied into FastPlay's own folder, and favorite folders have one to paste into them.
iPhone: VoiceOver no longer lists actions such as Delete, Download and Remove twice on files, favorites, servers, addresses and auto synced folders.
iPhone and Android: Keep Screen On, in Settings > Playback under This Device, stops the screen dimming and locking by itself while FastPlay is in front.
FastPlay for Android: the iPhone app's screens and features on Android phones (Files on the device, Dropbox, FTP, SFTP and SMB servers, radio, podcasts, Open Address, the player with its sliders and touch mode, and the same settings), with TalkBack, and YouTube through yt-dlp (search, channels, playlists, favorites and downloads), which it keeps up to date by itself. Download FastPlay.apk from the latest release.
Add a "Show chapter title in window title" option on the Playback tab. For a file with chapters (an audiobook, a podcast with chapter marks), the window title names the chapter playing after the track name and keeps up as playback moves through them. On iPhone, the player screen shows the chapter playing under the title.
Add an Installed tools source in the YouTube options to use yt-dlp, Deno, FFmpeg and ffprobe from PATH or custom paths, including standard Homebrew locations on macOS. In this mode FastPlay never downloads or updates tools. Add an offline Test tools button that reports paths, versions, JavaScript runtime support and errors without saving settings.
Fix saved hotkeys failing to load on macOS and the empty loaded list overwriting their saved count. Read action names as wide characters on every platform, preserving named actions, legacy entries and global/local flags across restarts.
3D Audio now renders with a built-in HRTF (the SADIE II KU100 dummy head measurements) instead of Steam Audio, so FastPlay no longer needs the 50 MB phonon.dll. Binaural and 5.1 virtual surround work as before, with the same width, rotation, listener position, rear speaker and blend settings, at about the same loudness. The no-steamaudio build option is gone.
FastPlay's windows are now built with wxWidgets instead of raw Windows dialogs, as a step toward versions for other systems. Every window keeps its title, controls, labels, keyboard shortcuts and speech. Things you may notice: tabbed windows (Options, Radio, Podcasts) now also switch tabs with Ctrl+Tab and Ctrl+Page Up/Down, and each tab shows only its own labels (the old windows drew every tab's labels at once, so a label's Alt shortcut could jump to a control on another tab). The global hotkey field now speaks the keys you press, and names keys like Up and Home correctly instead of as numpad keys. Add Folder and the folder Browse buttons in Options use the modern Windows folder picker.
File > Exit now saves your position, playback state and settings, as closing the window always did. Previously Exit skipped saving.
Fix a crash when importing radio favorites from a file with no extension, and a possible crash when moving playlist items with Alt+Up/Down while the playlist changed underneath.
Replace the reverbs with two new ones. The reverb setting (Ctrl+5 or the Effects options) now cycles Off, Simple and Advanced; Freeverb, DX8 and I3DL2 are gone. Simple is a smooth 16 line reverb with a room preset (22 rooms, from small room to cathedral) plus mix, size, damping, width, pre-delay, low cut and high cut. Advanced is the OpenAL EFX reverb model with the 26 classic EAX environments (generic, padded cell, concert hall, sewer pipe, psychotic and so on) plus mix, decay, high frequency decay, density, diffusion, reflections and tail levels and delays. Choosing a room or environment sets the other values, which you can then adjust. For both, a mix of 50% keeps the dry sound at full level with the reverb at its natural level, and 100% is reverb only. Existing Freeverb settings carry over to Simple, and DX8 or I3DL2 settings switch to Advanced. Convolution reverb is unchanged.
Fix seeking with the Speedy and Signalsmith tempo algorithms. Seeking now takes effect immediately instead of first playing out up to a second (or more, depending on the buffer size) of audio from the old position, and Signalsmith no longer leaves a short gap of silence after each seek. The reported position now matches what you hear; it used to run ahead by the playback buffer times the speed (over a second at high speeds), which made relative seeks, rewind on pause, bookmarks and remembered positions land in the wrong place.
Fix the end of files being cut off with the Signalsmith tempo algorithm (around the last 150 ms, more at slower speeds), and a few milliseconds being lost at the end with Speedy.
Fix a possible hang when changing tracks or audio devices while using the Speedy or Signalsmith tempo algorithms, and fix loud clicks with Speedy on audio that reaches full scale.
Fix shuffle replaying the same tracks before others have played in small playlists. Shuffle now builds a random order and plays through the whole playlist once before reshuffling, instead of picking a fresh random track on every advance. Previous also retraces the shuffled order. A fresh order is generated each time shuffle is turned on and each time a new playlist or folder is loaded, and the random order now differs between launches (it was previously the same every time the app started).
When the speak now playing / read title shortcut is used on a file with no title tag, it now speaks the filename instead of "No title".
Fix podcast feeds and episodes that rely on HTTP redirects. Adding a feed by URL that redirects from an https:// address to an http:// one (common with PowerPress feeds, e.g. an https canonical URL that 301s to the real http feed host) previously failed with "HTTP status: (not reached)" because Windows refuses to auto-follow an https-to-http redirect. Episodes whose download URL redirects (e.g. an https .mp3 that 302s to a delivery-script URL) could also fail to play. FastPlay now follows these redirects itself, across schemes and hosts, for both feed loading and playback.
Fix radio stations whose URL points at an .m3u/.pls playlist (rather than a direct stream) failing to play with "Cannot play file". Playing a saved favorite or an opened URL that is a remote playlist now fetches and resolves it to a real stream URL before playback, following up to three nested playlist levels. Previously this only worked for stations found through the search tab.
Add ReplayGain support for loudness normalization. New options on the Playback tab let you choose Off, Track, or Album gain, set a preamp in dB, and prevent clipping using the peak tag. FastPlay reads REPLAYGAIN_TRACK_GAIN / REPLAYGAIN_ALBUM_GAIN tags from FLAC, OGG, Opus, MP3 (APE or ID3v2), and other tagged files and adjusts playback volume accordingly. Files without ReplayGain tags, and live streams, play unchanged. Defaults to Off so nothing changes until you enable it.
Fix radio favorites losing their order when imported from an M3U/PLS playlist. Imported stations now keep the order they appear in the file, so a custom order you arranged and exported survives a re-import instead of reverting to alphabetical. Importing also skips stations whose URL you already have, so re-importing no longer creates duplicates.
Fix password-protected podcast feeds failing with a 401 error after restarting FastPlay. The username and password entered when adding a podcast are now saved with the subscription and used every time episodes are loaded, and also when downloading episodes. Previously they were only used once at add time, so the feed kept working only as long as Windows had the credentials cached. If you have a protected podcast that stopped returning episodes, add it again with the same feed URL and your username and password to update the stored credentials.
The episode list in the Podcasts dialog is now multi-select. Use Shift+Up/Down to extend the selection, Ctrl+Up/Down to move the focus without changing selection, and Ctrl+Space to toggle the focused episode. Pressing Enter adds all selected episodes to the playlist and starts playback; the Download button downloads all selected episodes (skipping any that already exist on disk).
Fix selection jumping to a different song in the Song History dialog after Ctrl+C copy. The listbox's built-in prefix-search was consuming the stray control character generated by the Ctrl+C keystroke.
Add Help > Readme to open the bundled docs\readme.txt in the default text editor.
Add Ctrl+D / File > Add Stream to Favorites to save the currently playing stream URL to radio favorites. Refuses silently if nothing's playing, if the current item isn't a URL, or if the stream is already in favorites.
Add a Country filter to the RadioBrowser search tab. Select a country (or leave "(Any)") to restrict search results. The country list is fetched once per session in the background, ordered by station count; the combo is editable so you can type a country name directly. The filter is hidden when the search source is not RadioBrowser. With a country selected, you can leave the search box empty and hit Search to browse all stations from that country, sorted by popularity.
When a podcast feed fails to load, show a diagnostic dialog with the feed URL, HTTP status, any Win32 / WinInet error, bytes received, number of <item> tags found in the XML, number of episodes extracted, and a preview of the response body. Applies to loading episodes for a subscribed podcast and to adding a new podcast by URL.
Add Ctrl+1 through Ctrl+0 to quickly enable/disable effects: Ctrl+1 Volume, Ctrl+2 Pitch, Ctrl+3 Tempo, Ctrl+4 Rate, Ctrl+5 Reverb, Ctrl+6 Echo, Ctrl+7 EQ, Ctrl+8 Compressor, Ctrl+9 Stereo Width, Ctrl+0 Center Cancel, Ctrl+- Convolution Reverb, Ctrl+= 3D Audio. Convolution Reverb is also now assignable as a global hotkey.
Switch update checks back to the GitHub releases API so updates pick up the latest release from the masonasons/FastPlay repository. The build script now compares against the built commit SHA in addition to the version string.
download-deps.bat now fetches the Steam Audio SDK (phonon.dll, phonon.lib, and the phonon.h headers) automatically, so a fresh clone no longer requires a manual Steam Audio download for 3D audio support.
When reordering stations or podcast subscriptions with Ctrl+Up/Ctrl+Down, speech feedback is now consistently "X moved below Y" (where Y is the item directly above the new position), instead of using different phrasing for top/middle/bottom positions. Moving to the top slot is announced as "X moved to top".
Fix focus being lost when an error message appears on top of an open dialog (e.g. Radio). Error messages now return focus to the dialog that was active, rather than the main window.
Replace the file types options tab with a single "Register all supported file types" checkbox on the playback tab. When enabled, all formats are registered on startup.
Expand supported file associations to include MP1, MP2, MP4, WMV, M4R, AIF, RMI, KAR, DFF, DSF, CDA, ALAC, and tracker formats (MOD, S3M, XM, IT, MTM, UMX).
Add song history. Stream metadata (song titles from internet radio) is now captured into a persistent database across all stations. Open the list with Ctrl+Shift+H or File > Song History. The dialog shows the last 100 songs with date and time, and has Copy and Close buttons. Press Ctrl+C to copy the selected song to the clipboard.
